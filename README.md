# Week 3 – Analytical Model Development and Validation

## Project: Customer Churn Prediction

This project is part of my Data Science Internship – Week 3 task.

### Objective

The objective of this project is to develop and validate a predictive machine learning model for customer churn prediction.

### Models Studied

* Logistic Regression
* Decision Tree
* Random Forest

### Selected Model

Random Forest was selected because it can handle complex patterns and provides good classification performance.

### Model Development Process

1. Data Collection
2. Data Cleaning
3. Feature Selection
4. Train-Test Split
5. Model Training
6. Prediction
7. Model Validation
8. Model Comparison

### Train-Test Split

* 80% Training Data
* 20% Testing Data

### Evaluation Metrics

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix
